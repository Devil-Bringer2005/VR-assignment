# VR Shape Placement Puzzle

## Overview

VR Shape Placement Puzzle is an interactive virtual reality puzzle game developed in Unity using the **XR Interaction Toolkit** and **Unity's New Input System**.

The player is placed inside a virtual room and must identify three different geometric objects — a **Cube, Sphere, and Cylinder** — and place each object into its corresponding target socket.

The puzzle is time-limited. The player must correctly place all three objects before the countdown reaches zero.

Successfully completing the puzzle opens the room's door and displays a **Task Completed** message.

---

# Gameplay Objective

The main objective is simple:

> **Place all three objects into their correct sockets before the timer expires.**

The three objects are:

- Cube
- Sphere
- Cylinder

Each object has a unique target socket.

For example:

```text
Cube      → Cube Socket
Sphere    → Sphere Socket
Cylinder  → Cylinder Socket
